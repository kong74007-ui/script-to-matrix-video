# 九宫格开场·全屏展示

独立模板 ID：`nine-grid-reveal`。这是新动效结构，不是已有 `ref-*` 模板的别名，也不改变它们的随机时长规则。

## 固定设计

- 1080×1920、30fps、12秒。12秒按用户提供的11.933秒参考视频取整，保留该参考的动效与音乐节奏；不要套用 `ref-*` 文字模板的随机时长。
- 黑底、3×3直角竖向视频格，3px黑缝，无圆角。
- 九格按行编号1～9，显现顺序5、4、1、2、3、6、9、8、7，首帧分别为5、23、32、42、51、60、68、78、85（从0计帧）。逐格直接显示，不渐入、不滑动。
- 第96帧切全屏，同时仅一帧1.17倍放大及HyperFrames原生Blur 0.10；第97帧恢复清晰正常比例。固定文字从第0帧开始显示，持续到12秒结束。
- 全屏素材在3.2、6.3、9秒切换。不要把参考源视频的手持晃动或拍摄旋转当成模板动画。
- 标题：居中、白色Noto Serif SC 900、82px、黑描边和投影，两侧破折号；最多9字符。底部短句：白色Noto Sans SC 900、58px，最多16字符。无文字渐入。
- BGM固定绑定当前参考音轨，与12秒动效一起复用；不重新检索、随机换曲或参与批量BGM轮换。标题、CTA和视频素材可替换，音乐不是任务变量。

## 输入与准备

先按主Skill规则验证自己的素材库连接，再选9条独立的已审核视频。允许用户直接提供视频；禁止AI生成素材。

输入JSON示意（路径必须是当前机器上的文件）：

```json
{
  "title": "输入公司名称",
  "tagline": "品质｜细节｜诚信｜口碑",
  "grid": [
    {"path": "local-video-1.mp4", "source": "user"},
    {"path": "local-video-2.mp4", "status": "可使用", "record_id": "library-id"}
  ],
  "main": [
    {"path": "local-main-1.mp4", "source": "user"},
    {"path": "local-main-2.mp4", "source": "user"},
    {"path": "local-main-3.mp4", "source": "user"}
  ]
}
```

`grid`示意只列两项，实际必须9项；按行从左上到右下排列。九格原视频均至少3.2秒，内容不得重复。`main`必须3项，可复用九格中的素材，其原视频至少分别6.3、4.7、5秒；源入点分别3.2、2、2秒。无需输入`bgm`。

绑定音频位于模板内`assets/audio/reference-bgm.m4a`，为用户提供的参考视频原音轨的已验证12秒AAC版本。`template.json`保存路径、SHA-256、0秒起点和音量1。准备脚本校验文件完整性后原样复制，不重新编码、不改变播放速度、音量或淡入淡出，保留既有卡点。文件丢失或校验失败时停止并提示恢复模板音频，不从素材库挑另一首顶替。

为兼容旧任务，若仍传`bgm`，只能是与绑定文件字节完全相同的本地文件；不同曲目、`auto`、空值或静音参数会明确报错。用户明确要求换曲或静音时，作为单独定制处理，不悄悄改变这个模板的绑定规则。

模板包含该绑定音频，迁移时须连同音频一起复制，无需再次定位桌面参考视频。仓库所有者已确认将绑定音频随模板公开同步；音轨来自用户素材，不因此成为开源音频，其他使用者仍须确认自身使用权限。模板不打包客户视频、服务器地址或凭据。

在新任务输出目录准备，不要往模板源目录里填客户素材：

```powershell
python scripts/prepare_nine_grid.py job.json --template-dir assets/templates/nine-grid-reveal --output-dir <new-project>
```

准备脚本会识别HLG/PQ视频并实际转换为Rec.709 SDR，不能只改颜色标签；HyperFrames的Blur仅作用于转换后的SDR素材。

进入生成项目后，先用HyperFrames `check --snapshots --json`验证，再以`hyperframes@0.8.33 render --sdr --fps 30 --quality high --workers 4 --output <final.mp4>`出片。Windows下所有CLI/FFmpeg子进程使用隐藏窗口，沿用Skill现有隐藏运行工具或`subprocess.CREATE_NO_WINDOW`。

源HTML只声明title、tagline、grid1～grid9、main1～main3变量。音频元素直接使用绑定文件路径，不暴露`bgm`覆盖变量。优先用准备脚本生成完全本地化的项目。

## 验证

检查第0帧标题和底部短句、0.17秒中心格、2.9秒完整九格、3.2秒冲击帧、3.233秒恢复清晰正常比例及结尾；文字须始终可见。最初5帧为黑底文字，九格尚未开始显示，不是缺失素材；此后不得出现意外黑屏。验证12秒、360帧、H.264/AAC及非静音BGM；准备项目中的BGM须与模板绑定文件SHA-256相同，保留素材来源记录。
