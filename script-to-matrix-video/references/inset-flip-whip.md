# 小窗推拉·翻片甩切

ID：`inset-flip-whip`。2026-09-11 用户确认保存。源码：`assets/templates/inset-flip-whip/`。HyperFrames 0.8.34；仅明确选择本模板时调用，不改变普通任务默认模式。公开离线源码不代表主站部署，线上只能提交实时目录返回的 ID。

## 固定设计

- 1080×1920、30fps、443帧（14.766667秒），不随机8–15秒。中间横屏窗口 x0/y656/1080×608，上下纯黑、直角，素材保持比例。
- 开头是同源、同时间、同构图的彩色裁切窗口叠在低饱和底片上，**不是缩小画中画**。彩色视频始终1080×608，只改变遮罩；窗口 x134/y164/812×280，0.4秒居中，0.55–1.1秒展开。之后恢复正常色彩。禁止把前景缩成另一张完整小图。
- 保留横向推拉甩切、曲面形状遮罩、斜切轻推近及六竖条收尾；遮罩动，不弯曲人物视频平面。不新增白色蒙层。
- 四段文字 `title/subtitle/body/cta` 从第一帧静态显示至最后一帧。Noto Sans SC900，96/82/62/86px；标题和CTA红色奶白描边，辅助文字黄色黑描边。顶部96px（5%）、CTA距底116px，详见 frame.md。不保留参考原文，不做文字动效。
- 绑定原 BGM，0秒入点、音量1，无渐入渐出/变速/轮换；校验 template.json.referenceAudio.sha256，缺失或失败须修复，不自动换音乐。

## 换素材和文案

1. 首次安装先连接自己的素材库。选7条不同已审核实拍视频或用户提供的视频，禁止AI生成或图片兜底。示意素材不作为经营效果证明。
2. 复制整个模板目录到新任务目录。公开模板没有演示视频，补齐 `assets/media/00.mp4` 至 `06.mp4`；每条选定入点后至少5秒，建议1280×720、30fps、SAR1:1、H.264/yuv420p/Rec.709 SDR、静音。按显示旋转后等比处理，不拉伸；HDR转换沿用 [三横屏准备规则](triple-strip-shutter.md)，不得只改色彩标签。
3. 在新任务目录运行 `python prepare_backplate.py`（需FFmpeg/ffprobe）。它检查七个视频和绑定BGM，重新生成 `00-opening-backplate.mp4`：前1.1秒 saturation0.15/brightness-0.03，随后正常色彩。前景仍用原00；底片不变时间和尺寸。每次替换00后必跑，禁止复用旧底片。不要以变量覆盖 media0；本模板统一替换上述固定文件路径，保留各槽源映射。
4. 10槽源编号依次 `00,01,02,03,01,04,05,06,01,02`，入点/时间窗见 template.json.media。复用是同源不同片段，不得把7条源都换成同一条；不开AI素材生成。
5. 文案写入 variables.json（仅四个文字字段），同时更新HTML默认变量及静态正文。标题建议12字内、CTA14字内；超长先缩短/合理换行，不压扁字体。保持已确认的字号层级、间距和描边。

```json
{"title":"想开店又怕养团队？","subtitle":"1个人＋AI员工","body":"也能运行一家门店","cta":"私信「OPC」了解模式"}
```

6. 记录私有来源信息在任务 provenance，不上传。运行 `npm run check`，检查首帧、0.4/0.8/1.1秒窗口对齐、各转场及14.733秒尾帧。运行时实时调色曾反复超时，因此使用已验证的预处理底片，不重加实时调色或CSS滤镜。
7. 需要成片时运行 `npm run render -- --quality high --fps 30 --workers 2 --variables-file variables.json --output renders/final.mp4`；验证443帧、1080×1920、H.264/AAC、音乐可听、尾帧非黑、人物不变形，并返回实际视频链接。Windows子进程隐藏窗口。保存时已通过预览/布局/动效检查，未附最终MP4。
