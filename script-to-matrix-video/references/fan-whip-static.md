## 固定内容

- 1080×1920，30 fps，377 帧（377/30 秒）。不套随机 8–15 秒，不伸缩音乐节奏。
- 三横带错时进入 → 扇形旋展 → 全屏素材 → 横向甩切、缩放擦除、纵向甩切。素材主段起点为第 64、122、185、248、311 帧；保持 HTML 中全部时间线不变。
- 字体 Noto Sans SC 900。标题 96px、CTA 86px，红字 `#d51b08`、奶白描边 `#fff3ca`（11/10px）及细深色外沿；副标题 82px、说明 62px，黄色 `#ffe018`，深色描边。行间距 8px，字距 -0.025em；顶部 96px（5%），CTA 距底部 116px。
- 四个文字字段 `title`、`subtitle`、`body`、`cta` 从第 0 帧显示到结束，不渐入、不渐出、不缩放、不倾斜；只有画面有动效。可换文案，不把参考海报的价格或承诺添加到新文案中。
- 原 BGM 固定绑定 `assets/media/reference-bgm.m4a`，从 0 秒开始、音量 1，不换曲、不参与批量随机轮换、不加淡入淡出。校验 `template.json` 的 SHA256；缺失或不符则修复模板，不自动替代。
- 所有视频按源显示方向、原比例缩放和 cover 裁剪。禁止把竖素材强行拉成横屏、独立拉伸宽高、加白色蒙层或圆角。扇形短段使用前三个视频各自的静帧，不是 AI 图片。

## 新任务准备

1. 按主 Skill 检查素材库连接，选择五条不同的已审核视频或用户提供的视频，保留记录 ID、原路径、入点。禁止 AI 素材、图片兜底或把同一个文件改名当五条。
2. 将模板目录复制到新的任务目录，勿直接在 Skill 目录渲染。模板包只含版式、字体、运行依赖和绑定音乐；不含客户素材。五条视频与静帧须在新任务中补齐。
3. 每条源视频从选择入点起必须至少有 4 秒。规范化为 4 秒、30 fps、H.264/yuv420p/Rec.709 SDR、SAR 1:1、静音 MP4。尊重显示旋转后按比例缩放（如 `scale=-2:1280,setsar=1`），不能固定宽高拉伸。HLG 的 libplacebo/BT.2390 转换沿用 [三横屏模板](triple-strip-shutter.md) 的已验证规则，SDR 不套 HDR 转换；不要只改颜色标签。记录处理参数和源色彩信息。
4. 五个槽位路径依次为 `assets/media/01-aspect-fixed.mp4`、`02-aspect-fixed.mp4`、`03-aspect-fixed.mp4`、`04-aspect-fixed.mp4`、`05.mp4`（均在同一目录）。名称是历史兼容接口，不限制横竖方向。前三条分别在第 1 秒提取同名 JPG（`01-aspect-fixed.jpg` 至 `03-aspect-fixed.jpg`）。三个静帧必须来自对应的新视频，不能沿用上一任务图片。
5. 在任务目录保存 `variables.json`，四个字段均为字符串，例如：

```json
{"title":"想开店又怕养团队？","subtitle":"1个人＋AI员工","body":"也能运行一家门店","cta":"私信「OPC」了解模式"}
```

同步更新新任务 HTML 的变量默认值及对应 `data-var-text` 静态正文（正确转义 HTML 和属性中的 JSON），与 `variables.json` 保持一致，使检查、Studio 和最终渲染使用相同文案。标题建议不超过 12 字，副标题与说明各 14 字，CTA 14 字；这些是排版建议，不是保证，换文案后需检查实际溢出，不压扁字体。

6. 记录任务 `provenance.json`。校验绑定音乐复制前后 SHA256 一致。在项目运行 `npm run check`，查看首帧、旋展、明亮素材和尾帧。确认后运行 `npm run render -- --quality high --fps 30 --workers 2 --variables-file variables.json --output renders/final.mp4`。Windows CLI 和辅助进程使用无窗口/隐藏运行。
7. 检查 377 帧、1080×1920、H.264/AAC、BGM 非静音。开场横带尚未入场区域及旋展背景短暂黑色是固定设计，不等于末尾缺素材黑帧。文字在浅色背景下有少量瞬时对比度告警，需视觉检查，不声称所有背景对比度都完全合格。返回实际 MP4 链接。
