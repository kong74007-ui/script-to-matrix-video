# 保存新模板与 GitHub 同步

适用：仓库所有者明确要求保存已确认的新模板或更新其 Skill 模板。普通成片、试做、预览微调不触发发布。

仓库所有者于 2026-09-11 明确设定：每次保存新模板，同时更新本机 Skill 和 GitHub 的 `kong74007-ui/script-to-matrix-video`，包含模板绑定 BGM；不能只保存到本机后宣称完成。此约定仅用于该所有者的维护请求，不授权其他使用者修改不属于自己的仓库。若后续指定仅本机、私有或不上传，以新指令为准。

1. 保存确认版源码、字体和许可证、运行依赖、音乐及校验值；保留字体排版、静态文字、素材比例和固定动效时序。准备说明写清换文案、换素材和检查方法。
2. 更新本机路由、模板目录和相关说明。模板原视频、客户/素材库视频、参考截图、项目日志、个人绝对路径、凭据及 `.env` 不属于默认公开内容；示例成片另行确认。检查绑定媒体是否存在额外保密或许可限制，遇到实质冲突再说明并暂停相关文件发布。
3. 从已核实的 Git remote 获取最新主分支；只移植本次模板及必要的文档修改，不覆盖同事的平台版正文或其他未提交工作。区分本机资产数、仓库资产数、线上实时目录；保存源码不代表部署服务。
4. 验证 Skill 结构、依赖文件、BGM 哈希、差异及敏感信息；保留已验证成片证据。提交本次明确文件，正常推送，不强推、不自动部署服务器。
5. 查询远程主分支确认包含提交，核实模板与绑定 BGM 均已上传，再报告本机/GitHub 状态和链接。推送被拒或网络结果不确定时先查远端，不重复提交；不能完成则如实报告，不称已同步。

除非用户明确要求安装包或 Release，本流程不额外创建发行版；GitHub 源码归档随提交更新。
